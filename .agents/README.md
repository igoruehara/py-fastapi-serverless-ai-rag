# .agents

Este diretório contém instruções locais para agentes de IA que forem evoluir o projeto.

As skills estão em:

```text
.agents/skills/
```

Cada skill descreve:

- Quando usar.
- Quais arquivos ler.
- Como executar a tarefa.
- Qual critério de pronto seguir.

Esses arquivos não substituem `AGENTS.md`; eles complementam as instruções globais com fluxos específicos.
